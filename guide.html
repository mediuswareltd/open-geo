Guide ​

A Next.js 14 property map dashboard with Leaflet/OpenStreetMap, filters, inspection reports, and CSV/PDF export.

](https://mediuswareltd.github.io/open-geo/)

A full-stack GIS-style property dashboard built with Next.js 14, Leaflet.js / OpenStreetMap, TailwindCSS, and a mock REST API. Suitable for portfolio and client demonstrations.

Features ​

FeatureDetails
Interactive MapOpenStreetMap tiles via Leaflet.js, colour-coded CircleMarkers by status
Property SearchReal-time search by address, owner, or ID
Dynamic FiltersFilter by property type, status, and max price
Property DetailsFull details panel (owner, price, area, zone, year built, coordinates)
Inspection ReportsPer-property inspection reports with condition rating, notes, and issues list
PDF ExportSingle-property detail PDF or filtered-list PDF via jsPDF
CSV ExportDownload filtered property list as CSV
REST APIMock Next.js API routes: GET /api/properties, GET /api/properties/:id, GET /api/reports/:id

Tech Stack ​

  • Frontend: Next.js 14 (App Router) · TypeScript · TailwindCSS
  • Map: Leaflet.js · react-leaflet · OpenStreetMap tiles
  • Icons: lucide-react
  • Export: jsPDF · jspdf-autotable
  • Backend: Next.js API Routes (mock data)

Getting Started (Local) ​

bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Open in browser
open http://localhost:3000

Deployment (Linux) ​

bash
# Install Node.js 20+ (Ubuntu/Debian)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Clone and install
git clone <repo-url> geo-report-dashboard
cd geo-report-dashboard
npm install

# Build for production
npm run build

# Start production server
npm start
# or with PM2:
# npm install -g pm2
# pm2 start npm --name "geo-dashboard" -- start

API Endpoints ​

MethodEndpointDescription
GET/api/propertiesList all properties
GET/api/properties/:idGet single property
GET/api/reports/:idGet inspection report for property

Mock Data ​

15 properties across Dhaka (Uttara, Gulshan, Banani, Mirpur, Dhanmondi, Motijheel, Bashundhara, Wari, Mohammadpur, Tejgaon, Shyamoli, Rampura, Malibagh, Kakrail) with full inspection reports.

# Getting started

Install and run **Open Geo** locally.

## Prerequisites

- Working knowledge of TypeScript
- Git and a terminal

## Install

```bash
npm install
```

## Quick start

```bash
npm run dev
# live demo: https://open-geo.vercel.app
```

# Guide

## What it is

A Next.js 14 property map dashboard with Leaflet/OpenStreetMap, filters, inspection reports, and CSV/PDF export.

## Stack

`Next.js 14`, `Leaflet`, `Tailwind`, `TypeScript`

## Live demo

[https://open-geo.vercel.app](https://open-geo.vercel.app)

## Capabilities

### Interactive map

OSM tiles with status-coloured markers.

### Search & filters

Address/owner/ID search plus type/status/price filters.

### Reports

Inspection details with condition, notes, issues.

### Exports

CSV and PDF via jsPDF.

# About Open Geo

## Who maintains it

Open Geo is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/open-geo](https://github.com/mediuswareltd/open-geo).

## Why it exists

A Next.js 14 property map dashboard with Leaflet/OpenStreetMap, filters, inspection reports, and CSV/PDF export.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/open-geo/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
